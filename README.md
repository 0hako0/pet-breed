# わんにゃんライフ 3D 🐶🐱

ブラウザで遊べる 3D ペット育成ゲームです。犬12種・猫12種から家族をむかえて、お世話・お散歩・芸のトレーニングで育てます。

## 起動方法

ES Modules を使っているため、`index.html` を直接開くのではなくローカルサーバー経由で開いてください。

- `start.bat` をダブルクリック（Node.js が必要）
- または、ターミナルで次を実行して http://localhost:8080 を開く

```bash
node server.js
```

インターネット接続が必要です（three.js とフォントを CDN から読み込むため）。

天気と季節は URL で試せます（例: `http://localhost:8080/?season=winter&weather=snow`。season は spring / summer / autumn / winter、weather は sunny / cloudy / rain / snow）。

ステータス（おなか・きげん・せいけつ・げんき・けんこう・なかよし）は時間とともに変化し、ゲームを閉じている間もゆるやかに進みます（最大10時間分・下限あり）。データはブラウザの localStorage に自動保存されます。

## 更新するとき

`index.html` で読み込むファイルには `?v=…` のバージョン番号がついています（スマホのブラウザが古いファイルと新しいファイルを混ぜて使わないようにするため）。
コードを変えたら、コミットの前に次を実行してください。

```
sh tools/bump-version.sh
```
