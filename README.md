# わんにゃんライフ 3D 🐶🐱

ブラウザで遊べる 3D ペット育成ゲームです。犬12種・猫12種から家族をむかえて、お世話・お散歩・芸のトレーニングで育てます。

## 起動方法

ES Modules を使っているため、`index.html` を直接開くのではなくローカルサーバー経由で開いてください。

- `start.bat` をダブルクリック（Node.js が必要）
- または、ターミナルで次を実行して http://localhost:8080 を開く

```bash
node server.js
```

インターネット接続が必要です（three.js とフォントを CDN から読み込むため）。

| 🥣 ごはん | 4種類。犬はおにく、猫はおさかなが大好物 |
| 🍪 おやつ | 5種類。ごきげん・なかよし度アップ。あげすぎると健康が下がる |
| 🎾 あそぶ | ボールなげ（取ってくる）／猫じゃらし（マウスで動かして追いかけっこ） |

| 🎓 芸 | おすわり・お手・おかわり・ふせ・まわって・ジャンプ・おじぎ・ごろん・ちんちん・ハイタッチ・バーン！（死んだふり）の11種。前提の芸やレベルで解放 |
| 🛁 おふろ | 清潔度回復。猫はちょっと嫌がる。終わるとブルブル |
| 🪮 ブラッシング | 清潔度・ごきげん・なかよし度アップ。猫はゴロゴロ |
| 💤 ねる | ベッドで眠って体力回復。眠くなると自分から寝ることも |
| 🐾 なでる | ペットをクリック。猫はさわりすぎると怒る |
| 💩 トイレ掃除 | ごはんの後しばらくするとうんちをする。クリックで掃除 |
| 🏥 びょういん | 健康が下がったら受診（コイン不足時は無料） |
| 🎀 きせかえ | 首輪・バンダナ・リボン・帽子・王冠・メガネなど14種 |
| 🛒 ショップ | コインでごはん・おやつ・アクセサリーを購入 |

ステータス（おなか・きげん・せいけつ・げんき・けんこう・なかよし）は時間とともに変化し、ゲームを閉じている間もゆるやかに進みます（最大10時間分・下限あり）。データはブラウザの localStorage に自動保存されます。

## ファイル構成

```
index.html        画面とUI
css/style.css     スタイル
js/main.js        ゲーム進行・操作・各アクション
js/petModel.js    犬種/猫種パラメータから3Dモデルを生成・ポーズ/アニメーション
js/breeds.js      犬種・猫種データ
js/world.js       部屋・公園・小物の3Dモデル
js/game.js        ステータス・アイテム・芸・セーブ
js/audio.js       効果音（Web Audio APIで合成）
server.js         依存なしのローカルサーバー
```
